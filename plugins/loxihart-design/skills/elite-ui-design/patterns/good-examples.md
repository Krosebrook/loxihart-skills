# Good Examples — Elite UI Design

## Experience Thesis Examples
- "Every interaction confirms you're in control" (dashboard tool)
- "Feels like a workspace, not software" (productivity app)
- "Fast enough that thinking isn't interrupted" (search/query tool)
- "Serious craft visible in every detail" (professional creative tool)

## Visual Direction That Works
- Void surface + electric accent: absolute authority, enterprise weight
- Warm off-white + ink type: editorial clarity, trust without coldness
- Deep navy + gilt: serious craft, premium without flashiness
- Desaturated + single saturated accent: focus and precision

## Phase 0 Context — Strong vs Weak

Weak: "It's a dashboard for analytics"
Strong: "B2B SaaS, power users (data analysts), they live in this app 6+ hrs/day,
speed and density matter more than handholding, dark mode expected"

## Anti-Slop Audit Pass Criteria
- Font choice is justified and distinctive (not Inter/Roboto/system-ui as primary)
- Background has atmosphere (not pure white or pure black)
- At least one layout decision that breaks the grid intentionally
- All interactive states exist: hover, focus, active, disabled, error, loading, empty
- Color contrast passes WCAG 2.2 AA at minimum
