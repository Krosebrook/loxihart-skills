# Sources and Numeric-Claim Policy

All normative or informative external requirements used by the library are cited to official W3C material. Catalog identifiers and code syntax are not treated as numeric requirement assertions. Adjustable numeric defaults are tagged as generated decisions.

- **target** — W3C WCAG 2.2 SC 2.5.8 Target Size (Minimum), Level AA — https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
- **contrast_text** — W3C WCAG 2.2 SC 1.4.3 Contrast (Minimum), Level AA — https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html
- **contrast_ui** — W3C WCAG 2.2 SC 1.4.11 Non-text Contrast, Level AA — https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html
- **focus** — W3C WCAG 2.2 SC 2.4.7 Focus Visible, Level AA — https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html
- **resize** — W3C WCAG 2.2 SC 1.4.4 Resize Text, Level AA — https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html
- **keyboard** — W3C WCAG 2.2 SC 2.1.1 Keyboard, Level A — https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html
- **drag** — W3C WCAG 2.2 SC 2.5.7 Dragging Movements, Level AA — https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html
- **pause** — W3C WCAG 2.2 SC 2.2.2 Pause, Stop, Hide, Level A — https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html
