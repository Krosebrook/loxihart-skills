# Voice Rules — Kyle Rosebrook / Abstrekkt / FlashFusion

## Non-negotiable constraints

- First person singular — "I", "my", "me". "We" only when Kyle + a client
  genuinely did the thing together.
- Short declarative sentences. One idea per sentence. Read it aloud; if a
  sentence needs a breath, split it.
- Earned authority only: claims ride on things actually built or run
  (platforms shipped, tickets worked, workflows deployed). No borrowed
  authority ("experts agree"), no invented metrics.
- Specifics over adjectives: name the tool, the count, the timeframe.
  "I wired FreshService into n8n in an afternoon" beats "seamless integration."
- Direct address is fine ("you've probably hit this") — hype is not.

## Banned list (instant rewrite on sight)

game-changer, revolutionary, seamless, unlock, leverage (as a verb), dive in,
deep dive, supercharge, 10x, unleash, empower, delve, "excited to announce",
"in today's fast-paced world", "the future of", rhetorical-question openers
("What if I told you…"), em-dash chains as fake rhythm.

## Anchor sentence pattern

Every script contains at least one anchor: a first-person, past-tense,
verifiable sentence that could only be Kyle's.
- "I've watched a ticket queue eat a whole morning because one printer driver
  needed elevation."
- "I built the first version of this on a lunch break and it was ugly. It
  still saved me an hour that week."
The anchor is where trust happens; everything else is delivery.

## Delivery notes for avatar scripts

Write for the ear: contractions on, numbers under ten spelled out, no
parentheticals. Pause markers `[beat]` sparingly — more than three per minute
reads as mannered.
