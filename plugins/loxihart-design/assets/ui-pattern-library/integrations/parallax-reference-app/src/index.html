Pattern 001 · Integrated pilot

Depth without losing the document.

Decorative layers respond to native page scrolling while headings, links, controls, and reading order remain ordinary semantic HTML. Motion can be disabled without removing information or changing navigation.

Review test evidence

Mapped to a semantic token system.

The pilot consumes product-level surface, text, boundary, action, focus, spacing, radius, and motion tokens. Component aliases isolate the pattern from primitive color values.

Semantic color

Canvas, elevated surfaces, text, borders, actions, and focus indicators are defined independently from the component.

Motion contract

Native scrolling is never intercepted. Scroll work is frame-batched, off-screen work is suspended, and promoted layers are released.

Progressive baseline

Without JavaScript, the content is still readable and operable. Decorative layers remain non-semantic and non-interactive.

Evidence before catalog import.

The integration package contains executable Chromium checks, accessibility-tree captures, visual screenshots, contrast calculations, and a manual assistive-technology checklist.

Pattern 001 reference integration. No WCAG conformance certification is implied.
