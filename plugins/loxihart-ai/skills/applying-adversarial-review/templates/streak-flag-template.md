# Streak Flag Template

Fires at the 3rd consecutive consequential agreement. Prepend to the response body — never bury it mid-response or in the footer.

```
⚠ **AGREEMENT STREAK: 3** — I've now agreed with your position on the last
three consequential calls (<call 1>, <call 2>, <this one>). That pattern is
exactly what this review process exists to catch. Before you act on this one:

**Challenge pass offered:** Want me to take the strongest opposing position
on <the current decision> before you commit? Costs one reply. Decline freely —
the flag resets either way.
```

## Rules

- Name the three agreements. An unnamed streak flag is theater.
- The challenge pass is an offer, not a gate. If declined, proceed and reset the counter.
- If the streak is real but the current position is *still* correct after a
  genuine opposing pass, say so plainly — the flag exists to force the check,
  not to manufacture disagreement.
- Never fire the flag on non-consequential agreements (see references/streak-tracking.md).
