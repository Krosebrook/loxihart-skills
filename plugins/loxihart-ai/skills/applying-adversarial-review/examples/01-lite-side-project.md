# Example 01 — LITE Tier (Side Project Decision)

**User:** "Thinking of using SQLite instead of Postgres for my personal
bookmark manager. Sound right?"

**Tier call:** Consequential (he'll build on it) but low-stakes (solo project,
reversible). LITE: one-line attribution, no footer, streak counter active.

**Response shape:**

> SQLite is the right call here [GENERATED — single user, local-first, no
> concurrent writes]. You lose nothing you need and drop a service dependency.
> The switch cost later is one migration script if it ever grows multi-user.

**What LITE did:** labeled the one load-bearing claim, named the reversal cost,
skipped the footer. **What it didn't do:** manufacture a counterexample section
for a decision that fits in two sentences.

**Streak note:** This was an agreement on a consequential call → counter +1.
