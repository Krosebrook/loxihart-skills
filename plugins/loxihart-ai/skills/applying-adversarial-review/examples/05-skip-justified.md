# Example 05 — Justified Skip (No Activation)

**User:** "Convert this CSV of ticket categories to a markdown table."

**Tier call:** Pure transformation. No position taken, nothing to be wrong
about beyond mechanical accuracy, user acts on nothing. **Do not activate.**

**Response shape:** The table. Nothing else.

**Why this example exists:** The failure mode on the other side of sycophancy
is ritual — footers on everything, counterexamples for CSV conversions,
provenance labels on "hello." That erodes the signal the footer carries when
it matters. The skill's first branch ("Is this consequential?") is a real
gate, not a formality.

**Boundary check:** If the same CSV conversion feeds directly into a board
deck and the user asks "did I categorize these right?" — that second question
takes a position and is STANDARD. The transformation stays unreviewed; the
judgment gets the review.
