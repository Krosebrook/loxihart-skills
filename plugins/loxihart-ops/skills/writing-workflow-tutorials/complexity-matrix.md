# Complexity Matrix — FlashFusion Tutorial Levels

Detailed calibration for Beginner / Intermediate / Advanced. Use this when Rule 2 or Gate 5 are ambiguous.

---

## Attribute Table

| Attribute | Beginner | Intermediate | Advanced |
|---|---|---|---|
| Step count | ≤ 8 | 9–15 | 16+ |
| Max time | 15 minutes | 45 minutes | Open-ended |
| Code blocks | None | Allowed with line-by-line explanation | Assumed readable without explanation |
| Paid tools | Free preferred; free tier OK | Paid OK; note cost | API access or paid tier required |
| Screenshots | Recommended | Recommended | Optional |
| CLI / terminal | None | None | OK to require |
| API keys | None | None | Required |
| Prerequisites | None assumed | Some setup expected (account creation) | Technical background required |

---

## Hard Escalation Rules

If any of the following apply, the tutorial is at minimum that level — not negotiable:

| Condition | Minimum level |
|---|---|
| Any step requires a paid tier | Intermediate |
| Any step requires an API key | Advanced |
| Any step requires CLI or terminal | Advanced |
| Any step requires OAuth app creation | Advanced |
| Reader must understand a concept before acting | Intermediate |
| Any step has >3 nested conditions | Intermediate |
| Tutorial requires completing a prior session first | Intermediate |

---

## When to Split (Part 1 / Part 2)

Split instead of escalating difficulty when ANY of these apply:
- Word count exceeds 900 words with all steps included
- Step count exceeds 20
- Setup and the actual workflow are separable sessions
- Tutorial requires two or more separate paid tools that need configuration

Splitting rule: Part 1 ends at a verifiable checkpoint (reader has a working piece they can test). Part 2 assumes Part 1 complete.
